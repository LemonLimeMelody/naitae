# 시연 가이드

여섯 날의 시나리오를 발표자가 순서대로 재현하는 방법이다. 모든 기대 동작은 코드(`vehicle/sim/ScenarioScript.kt`, `app/NaitaeCoordinator.kt` 와 `Coordinator*.kt`, `data/SeedData.kt`)를 근거로 적었다. 등장하는 사람·일정·기록은 가상 페르소나 데이터다.

실행 환경은 둘이다.

| 환경 | 신호를 넣는 곳 | 이 문서에서 다루는 범위 |
|---|---|---|
| 시뮬레이터 모드(일반 Android 기기·에뮬레이터) | 앱 화면 오른쪽의 가상 콘솔 | 여섯 날 전체 |
| Pleos 모드(Pleos Connect Emulator v2.1.0) | PC 브라우저의 Virtual Console | Virtual Console 로 넣을 수 있는 구간. 넣을 수 없는 구간과 대안을 날마다 따로 적었다 |

여섯 날 전체는 시뮬레이터 모드에서 시연한다. Pleos 모드 절차는 어댑터 코드와 [`PLEOS_NOTES.md`](PLEOS_NOTES.md) 를 근거로 쓴 것이며, Pleos 에뮬레이터에서 실행해 본 결과가 아니다.

## 1. 시뮬레이터 모드 준비

APK 를 Android 9 이상 기기에 설치하고 실행한다([README 의 실행 방법](../README.md#실행-방법)). 화면은 가로로 고정된다. 앱을 실행하면 늘 평일 아침의 데이터로 시작한다.

### 화면 구성

- 왼쪽: 차량 화면. 상단 바에 앱 이름과 차 이름, 시계, 기어 표시(P 는 호박색)가 있다. 읽는 문장은 화면 아래 자막으로 나온다.
- 오른쪽: 가상 콘솔. 사이의 손잡이(`›`)를 누르면 접히고 차량 화면이 전체를 쓴다. 조작부가 화면보다 길면 스크롤된다. "시각 바꾸기"와 "다음에 할 말"은 조작부의 아래쪽에 있다.
- 시뮬레이터의 음성 출력은 소리를 내지 않는다. 문장을 자막으로 보여 주고 읽는 데 걸릴 시간만큼 기다린다.
- 실내 조명, 열선, 공조에 내린 명령은 가상 콘솔의 SDK 호출 로그로 확인한다.

### 가상 콘솔의 버튼

| 묶음 | 버튼 | 하는 일 |
|---|---|---|
| 날짜 | 평일 · 출근길 / 토요일 새벽 · 낚시 일정 / 일요일 · 가족 나들이 / 1년 뒤 같은 날 / 아빠 생일 아침 / 20년 뒤 · 선물 받은 새 차 | 시동을 끄고, 그날의 시작 시각, 좌석, 주행거리, 차(VIN)를 정한다. 앱은 그날 아침까지 쌓였을 데이터로 바꾼다. 같은 날짜를 다시 누르면 그날을 처음부터 다시 시작한다 |
| 차 | 시동 / 기어 P / 기어 D / 시동 끄기 | 시동을 걸면 기어는 P 다. 기어 D 에서는 주행거리가 조금씩 늘어난다 |
| 목적지 도착 | 회사 / 낚시터 / 수목원 / 마트 | 기어 D 로 출발해 그 장소까지 달리고, 도착 이벤트를 낸 뒤 기어 P 로 돌아온다. 주행거리는 회사 18km, 낚시터 32km, 수목원 41km, 마트 6km 가 늘어난다 |
| 좌석 착석 | 운전(고정) / 조수 / 뒤 왼 / 뒤 오 | 착석 여부를 바꾼다. 날짜를 고르면 그날에 맞게 정해지므로 시나리오에서는 누를 필요가 없다 |
| 지금 값 | 기어, 주행거리, VIN 끝자리, 날짜 · 시각, 차 | 표시만 한다 |
| 시각 바꾸기 | +10분 / +1시간 / 퇴근 18:40 | 같은 날 안에서 시각을 옮긴다 |
| 다음에 할 말 | 내일 세차 예약 / 올해 첫 감성돔 / 아빠, 내년에 또 오자! / 안내해 줘 | 다음 음성 입력 한 번이 돌려줄 말을 정한다 |
| SDK 호출 로그 | - | 앱이 부르는 API(호박색), 받는 이벤트(청록), 상태 메모(보라). 최근 200줄 |

### 음성 입력의 기본값

"다음에 할 말"을 누르지 않아도 시나리오에 맞는 말이 들어간다.

| 날짜 | 그날 도착하기 전 | 그날 도착한 뒤 |
|---|---|---|
| 평일 · 출근길 | "내일 세차 예약" | 말 없음 |
| 토요일 새벽 · 낚시 일정 | 말 없음 | "올해 첫 감성돔" |
| 일요일 · 가족 나들이 | 말 없음 | "아빠, 내년에 또 오자!" |
| 그 밖의 날 | 말 없음 | 말 없음 |

"다음에 할 말"로 넣은 말은 그다음 음성 입력 한 번(브리핑 끝의 메모 질문 또는 "한마디 남기기")에 쓰이고, 날짜를 바꾸면 비워진다. 길 안내 질문에는 음성 입력이 없으므로 "안내해 줘"를 미리 넣어 두면 그날의 다음 음성 입력이 그 말을 받는다. 길 안내는 차량 화면의 "안내해 줘" 버튼으로 답한다.

### SDK 호출 로그의 표기

시뮬레이터의 로그는 실제 SDK 호출이 아니라, 같은 지점에서 Pleos 어댑터가 부르는 API 를 알아볼 수 있게 붙인 이름이다. 어댑터의 실제 호출과의 대응은 [`SDK_USAGE.md` 9절](SDK_USAGE.md#9-시뮬레이터-로그-표기)에 있다. 시동과 기어를 넣을 때마다 아래 줄이 공통으로 나온다.

| 조작 | 로그 |
|---|---|
| 날짜 | `가상 콘솔 · 평일 · 출근길 · 2026-11-12 07:42 · 그랜저 12,800km · 1명 탑승`, `나이테 · '평일 · 출근길' 아침까지의 데이터로 바꿈` |
| 시동 | `CarPropertyManager · IGNITION_STATE = ON`, `CarPropertyManager · GEAR_SELECTION = P`, `나이테 · 시동 ON`, `Vehicle.light.checkAmbientLightBrightnessColorCapabilities() → 보라·파랑·청록·흰색`, `Vehicle.carInfo.getVINInfo() → KMHGRANDEUR000001` |
| 시동 끄기 | `CarPropertyManager · IGNITION_STATE = OFF`, `나이테 · 시동 OFF` |
| 기어 D / 기어 P | `CarPropertyManager · GEAR_SELECTION = D` / `= P`, 멈출 때 `CarPropertyManager · PERF_ODOMETER = …km` |
| 낭독 | 문장마다 `TextToSpeech.speak("…")`, `TextToSpeech · onDone` |

### 시연할 때 지킬 순서

1. 날짜 버튼을 누른 뒤 "시동"을 누른다.
2. 브리핑과 질문이 끝난 뒤에 목적지 버튼을 누른다. 목적지 버튼은 누르는 순간 기어를 D 로 바꾸므로 읽던 것이 멈춘다. 브리핑 도중에 출발해도 그날 브리핑은 마친 것으로 기록된다.
3. "다시 시동"은 "시동 끄기" 다음에 "시동"을 누르는 것이다.
4. 차량 화면의 버튼은 시동이 걸려 있고 기어가 P 일 때만 눌린다.
5. 브리핑을 줄이려면 브리핑 화면의 "그만"을 누른다. 그날 브리핑은 마친 것으로 기록되고 다음 단계(메모 다시 알림, 길 안내 질문)로 넘어간다.

아래 여섯 날의 순서는 `ScenarioScript` 가 정의한 발표 순서와 같다. 이 스크립트를 한 번에 실행하는 버튼은 가상 콘솔에 없으므로 순서대로 직접 누른다.

## 2. Pleos 에뮬레이터 준비

AVD 를 Cold boot 로 띄우고 APK 를 설치한 뒤 Virtual Console 을 연다.

```bash
adb forward tcp:8088 tcp:8088
```

PC 브라우저에서 `http://127.0.0.1:8088/` 을 연다. 음성 입력을 쓰려면 에뮬레이터의 Extended Controls → Microphone 에서 호스트 오디오 입력을 켠다.

### Pleos 모드의 동작

| 항목 | 동작 |
|---|---|
| 시동 | Vehicle SDK 에 시동 상태를 읽는 API 가 없다. 앱이 차량 서비스에 연결되어 기어 값을 처음 받은 때를 시동 ON 으로 본다. 연결된 뒤에 시동을 껐다 켜는 것은 구분하지 못한다. 앱을 강제 종료하고 다시 실행하면 새 시동으로 처리되지만, 도착해서 준비해 둔 기록 초안은 메모리에만 있어 이어지지 않는다 |
| 날짜와 시각 | 기기 시계를 쓴다 |
| 데이터 | 첫 실행 날짜를 기준으로 가상 페르소나 데이터를 한 번 만들어 앱 내부 저장소에 둔다. 일정이 있는 날은 2026-11-12, 2026-11-14, 2026-11-15 이고, 첫 실행한 해가 2027~2045년이면 그해의 11-15 가 더해진다. 편지는 첫 실행 날짜가 2027-11-01 이후일 때 데이터에 들어간다 |
| 첫 실행 | 차량에서 VIN 을 읽으면 가상 데이터의 차(그랜저)와 다르므로 이어받기 화면이 먼저 열린다. "나이테 보기"를 누르면 홈으로 간다 |
| 가상 콘솔 패널 | 없다. SDK 호출 로그를 보여 주는 화면도 없다. 앱이 설정한 값은 Virtual Console 의 카드에서 확인한다 |
| 권한 | 첫 실행에 위치(`pleos.car.permission.FUSED_LOCATION`)와 알림 권한을 묻는다 |

### Virtual Console 카드와 앱 동작

| 카드 | 앱이 받거나 설정하는 API | 앱 동작 |
|---|---|---|
| Gear Selection (P/R/N/D) | `GearSelectionListener.onSelected` | P 에서 시동 흐름과 화면 조작을 허용한다. P 가 아니면 낭독·연출을 멈추고 입력 화면을 닫고 터치를 잠근다 |
| Odometer | `DistanceDrivenListener.onDistanceDrivenUpdated` | 이번 이동 거리 계산, 이어받기 화면의 새 차 주행거리 |
| Seat Occupancy (동승석, 뒷좌석 좌우) | `SeatOccupancyListener.onSeatOccupancyUpdated` | 기록의 좌석 수, 새 차 첫 시동의 편지를 바로 열지 먼저 물을지 |
| Ambient Color, Ambient Brightness | `Light.setAmbientLightBrightnessColor`, `setAmbientLightBrightness` | 앱이 설정한 색과 밝기가 나타난다 |
| Seat Temperature(운전석) | `Seat.setHvacSeatTemperature` | 편지 연출의 시트 열선 |
| Steering Wheel Heat | `SteeringWheel.setHvacSteeringWheelHeat` | 편지 연출의 핸들 열선 |
| Target Temperature, Fan Speed, HVAC Power | `HVAC.setHvacTemperature`, `setHvacFanSpeed`, `setHvacPower` | 편지 연출의 온도와 풍량 |

### Virtual Console 로 넣을 수 없는 것과 대안

| 필요한 신호 | 쓰이는 장면 | Virtual Console | 대안 |
|---|---|---|---|
| 내비게이션 목적지 도착 | 회사·낚시터·수목원 도착, 남기기, 다시 보기 | 카드 없음 | 시뮬레이터 모드의 "목적지 도착" 버튼. 에뮬레이터의 내비게이션 앱이 `onDestinationArrived` 를 주는지는 문서에서 확인되지 않았다 |
| 시동 끄기와 다시 시동 | 퇴근길 메모, "오늘을 남길까요?" | 카드 없음 | 시뮬레이터 모드의 "시동 끄기"와 "시동" |
| 날짜와 시각 | 1년 뒤, 생일 아침, 20년 뒤 | 카드 없음 | 시뮬레이터 모드의 날짜 버튼 |
| VIN | 20년 뒤 새 차의 이어받기 | 카드 없음 | 시뮬레이터 모드의 "20년 뒤" 날짜. Pleos 모드에서는 첫 실행의 이어받기 화면으로 같은 로직을 확인한다 |
| 위치(근접 알림) | 장소를 붙인 메모 | 카드 없음 | 여섯 날의 시나리오에는 장소를 붙인 메모가 없다 |
| 실내 조명의 임의 색 | 함께 꾸미기, 다시 보기, 편지 | Ambient Color 카드는 Cyan, Blue, Purple, White 네 가지 | 앱은 네 색을 ARGB 값으로 보낸다. 카드에 어떻게 표시되는지는 문서에서 확인되지 않았다 |

## 3. 여섯 날

### 3.1 평일 · 출근길 (2026-11-12 목 07:42)

그랜저, 12,800km, 혼자 탑승. 오늘 일정은 10:00 거래처 미팅과 19:00 지우 피아노 학원 픽업이고, 엄마가 남긴 메모 "퇴근길에 우유 사 오기"가 있다.

**시뮬레이터 모드**

| 순서 | 누르는 것 | 화면과 음성 | SDK 호출 로그 |
|---|---|---|---|
| 1 | 날짜 "평일 · 출근길" → "시동" | 브리핑 화면. "좋은 아침이에요." 뒤에 다섯 줄을 하나씩 짚으며 읽는다: "오전 10시, 거래처 미팅이 있어요." / "저녁 7시, 지우 피아노 학원 픽업이 있어요." / "엄마 메모, 퇴근길에 우유 사 오기." / "토요일 낚시까지 이틀 남았어요." / "일요일 가족 나들이까지 사흘 남았어요." | `나이테 · 하루 첫 시동 → 브리핑 5줄`, 문장마다 `TextToSpeech.speak("…")` |
| 2 | (기다림) | "메모할 것 있으세요?" → "듣고 있어요" → 받아 적는 글 "내일 세차 예약" → "메모했어요 · 내일 세차 예약" → 홈 | `SpeechToText.request() · ko-KR`, `SpeechToText · onStartedRecognition()`, `SpeechToText · onUpdated("내일 세차 예약", isFinal = true)`, `TextToSpeech.speak("메모했어요.")` |
| 3 | 목적지 "회사" | 기어 표시가 D 로 바뀌었다가 P 로 돌아온다. 화면은 홈 그대로다(평소 도착) | `CarPropertyManager · GEAR_SELECTION = D`, `CarPropertyManager · PERF_ODOMETER = 12,818km`, `NaviHelper · onDestinationArrived(회사) · 18km · 31분`, `나이테 · 회사 평소 도착 → 화면 없음` |
| 4 | "시동 끄기" → "퇴근 18:40" → "시동" | 홈 위에 메모 카드 "엄마 메모 · 퇴근길에 우유 사 오기"(퇴근길이라 다시 알려 드려요)가 뜨고 "엄마 메모예요. 우유 사기."를 읽는다. 브리핑은 다시 하지 않는다 | `가상 콘솔 · 시각 = 18:40`, `TextToSpeech.speak("엄마 메모예요. 우유 사기.")` |

실내 제어 명령은 없다.

**Pleos 에뮬레이터**

| 장면 | 방법 |
|---|---|
| 첫 시동의 브리핑 | Gear Selection 을 P 로 두고 앱을 실행한다. 읽는 내용은 기기 날짜의 일정·메모다. 일정이 없는 날에는 "오늘은 일정과 메모가 없어요."를 읽는다 |
| 말로 메모 | "메모할 것 있으세요?" 뒤에 마이크로 말한다. `SpeechToText.request()` 가 차 안 엔진(ko-KR)으로 받아 적는다 |
| 주행 중 잠금 | 브리핑 중에 Gear Selection 을 D 로 바꾸면 낭독이 멈추고 홈으로 간다. P 로 돌리면 화면 조작이 다시 된다 |
| 회사 도착, 퇴근길 메모 | 넣을 수 없다(도착, 다시 시동). 시뮬레이터 모드로 보여 준다 |

### 3.2 토요일 새벽 · 낚시 일정 (2026-11-14 토 05:03)

그랜저, 12,840km, 혼자 탑승. 오늘 05:00 낚시(낚시터) 일정이 있다. 낚시터는 처음 가는 곳이다.

**시뮬레이터 모드**

| 순서 | 누르는 것 | 화면과 음성 | SDK 호출 로그 |
|---|---|---|---|

## 4. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 차량 화면의 버튼이 눌리지 않는다 | 시동이 걸려 있고 상단 바의 기어 표시가 P 인지 본다. P 가 아니면 화면 입력을 받지 않는다 |
| 브리핑이 다시 나오지 않는다 | 브리핑은 하루에 한 번이다. 같은 날짜 버튼을 다시 눌러 그날을 처음부터 시작한다 |
